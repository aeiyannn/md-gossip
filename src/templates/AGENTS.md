# Shared Agent Context

> **READ-ONLY FILE — DO NOT EDIT.** You are an AI coding agent working in this
> repo. First read `SKILL.md` — it is the manual guide for this system.
> This file is the protocol, not a place for notes. All agent writes go
> to `AGENTS.local.md` (gitignored, human-reviewed). A human promotes approved
> facts into `AGENTS.d/` manually.

## Protocol — MANDATORY, every session

**STEP 1 — READ (before writing any code)**
1. Read this file fully. It is small on purpose.
2. If `AGENTS.d/` exists, need more? Run: `rg "<keyword>" AGENTS.d/`
3. Or read one chunk: `AGENTS.d/<tag>.md` (tags below). Never read all of
   `AGENTS.d/` at once — defeats the point.
4. If `AGENTS.local.md` or `AGENTS.d/local/*.md` exist, read them LAST.
   They override shared facts.

**STEP 2 — WORK**
Apply every fact you loaded. Facts under `## Pinned` always apply.

**STEP 3 — SUGGEST (only when you learn a durable fact)**
Durable = stack choice, bug cause, convention, user preference, API contract,
deploy quirk. NOT ephemeral task state.

- Grep first: `rg "<key phrase>" AGENTS.local.md` — skip if present.
- Append ONE line to `AGENTS.local.md`:
      #tag short fact under 120 chars
- New tag? Mention it in your reply; do NOT edit this file's index.

**FORBIDDEN — never do these**
- Edit `AGENTS.md` in any way (no appends, no new sections, no "rules").
- Append to shared `AGENTS.d/*.md` files. Shared chunks are human-owned.
- Create files other than `AGENTS.local.md` / `AGENTS.d/local/*.md`.
- Delete or reorder lines you did not write this session.

Agents propose facts. Humans approve them. That is the contract.

## Tag index

(Used when `AGENTS.d/` exists — chunks are created on demand.)

- `stack`  — languages, frameworks, versions
- `style`  — code conventions, what to avoid
- `bugs`   — known issues + fixes
- `api`    — endpoints, auth, contracts
- `deploy` — infra, env, release process
- `prefs`  — user preferences
